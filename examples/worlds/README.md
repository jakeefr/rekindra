# Counterpoint quality study

This is an authored example, not a mandatory style or production template. It records one successful improvement path and its remaining limitations. The original synthetic geometric reference is generated by `scripts/make_variety_sources.py`; no personal images are included.

`counterpoint.scene.json` is the strongest fully Hermes-authored revision (IV), saved after four native-agent revisions and visual review. Replace its all-zero reference asset ID with the actual ID returned by inspecting the synthetic geometric reference in your local project before calling `rekindra_create_world`. The source evidence is four unequal pink/cyan/yellow/violet stacks and a cream baseline. Three-dimensional ribbons, materials, twists and the curved support are inventions, not recovered geometry.

The initial III mesh exceeded the expression-work limit; Hermes lowered tessellation while preserving its equations. IV uses 88x24 samples per blade. This is a real quality/performance tradeoff, not evidence of arbitrary complexity support. One V preview timed out while other local browser work was running; a sequential retry of the same plan succeeded. Contention is a possible cause, not an established diagnosis.

Decoded-video reviews are sampled visual inspection, not continuous human-like watching or a collision proof. II and IV each received 24 decoded-frame inspection; V also received 24 decoded-frame inspection. All use Rekindra's original renderer/exporter, with no production external creative engine.

Remaining artistic issues: the source-driven four-column arrangement still resembles a line of studies; cyan's neck is narrow; some transitional tips look hooked; fine rib detail is barely visible; dark shading marks can occur near thin geometry. This pass improves composition and transformation substantially over the rejected tower baseline, but does not establish universal creative excellence, exact recovery or a completed hackathon product.
